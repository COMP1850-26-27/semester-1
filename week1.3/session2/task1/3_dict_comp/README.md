# Home Sensor Filtering

Scenario: A home automation system checks the battery levels of various smart sensors across a house. The system needs to trigger a maintenance alert, but only for sensors whose battery life has dropped below 20%.

1. Edit `sensor_filtering.py`.

2. Write a dictionary comprehension that filters an existing dictionary, keeping only the devices that have a battery level less than 20.

3. Run the program to verify its output.
