# Word Counter

1. We want count how many words are in a file. You can use any of the .txt files to test this.

2. Edit `word_counter.py` and add lines of code to:

    - Ask the user for the file name
    - Open and read the content of the file

    - Count how many words are in the file
        - There are multiple ways of doing this.
    - Display the word count. 

Hints: 

- You have learned how to read list of 
- You could use .split() to break up by spaces
- Watch out for empty lines that might give you empty strings


Here are the word counts you should get:
- story.txt - 290
- story2.txt - 326
- glasses.txt - 210
