# Write User Information to a File

1. Edit `user_info.py`.

2. We want to write user information to a file.

3. Add codes to prompt the user to enter their name, age, and favourite colour.

4. Add codes to open a file called `user_info.txt` for writing.

5. Write each piece of information to the file, each on a new line.
    
    Hints:
    - Remember to add `\n` for new lines when writing to files

6. Optional: extend this by using a loop to allow multiple people to enter their info in a row

    - If you want multiple people to add info without overwriting, consider append mode `a`
