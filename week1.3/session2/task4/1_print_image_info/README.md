# Retrieve PGM image info

We want to write a program to open a pgm image, and print out basic information of the image such as the dimensions and maximum gray value.

1. Edit `print_image_info.py`.

2. Write codes to open a PGM image file and read the content. 
    
    - You could handle file errors with try/except.

3. Print the dimensions and the maximum gray value in separate lines.
