# Inbox Task

You're in the data team for Leeds Eats, and your inbox is always filling up with requests from the various managers who need data - you've been asked to work through all the outstanding requests today.

For each email:

1. Write a query in `inbox.sql` that answers the question.
2. Run it on `leeds_eats.db`.
3. Under the query, write a one-sentence reply to the manager as a comment (`-- ...`).

Any emails you don't finish are independent practice!

---

## Easy

### Email 1

**From:** Customer Service Manager, Leeds Eats
**Subject:** Delivery fees

Hi team,

What is the average delivery fee across all our orders? Please round it to 2 decimal places. I need the figure for a meeting.

Thanks!
