# Challenging Yourself

*Even if you have done databases to some extent before, you should ensure you are paying attention to the theory topic.*

There is a very nice library which allows you to run sqlite using Python. In week 11, everyone will learn about this but for if you are confident in your ability to use python and to do some SQL, you can have a headstart.

(The library docs)[https://docs.python.org/3/library/sqlite3.html].

Create an interactive python program which allows you to:
- Effectively filter & search the database
- Export data as csv files
- **big challenge** Use the filtered data to produce some suitable graphs.

For example, being able to see a pie chart of the %s of restaurants are which cuisine, or being able to export all the restaurants in a certain area.
