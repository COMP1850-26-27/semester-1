# Advanced Practice Tasks

These advanced optional challenges build on the same ideas covered in Week 1 Session 2: printing, input, converting strings to numbers, basic maths (including modulo and integer division), string methods, and `try`/`except` for simple validation. Each file contains TODO notes to guide your solution.

## Task Overview
- `1_trip_planner.py` – calculate average speed for a trip in miles per hour, with basic validation.
- `2_budget_breakdown.py` – total and average three expense amounts, formatted to two decimal places.
- `3_clean_message.py` – tidy a free-text message using multiple string methods.
- `4_deadline_breakdown.py` – convert minutes into days, hours, and minutes using integer division and modulo.
- `5_safe_divider.py` – perform division safely, handling bad input and division by zero.
