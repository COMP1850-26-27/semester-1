
# Creating simple functions

Implement functions that:
- calculate and returns the area of a rectangle.​
- accept an integer value and returns a list of even integers between 0 and that value.​
- accept a list of integers and returns the mean average of the list.​

In each case choose an appropriate name:
- for the function
- for the inputs
- for the output

Write some code to test your function
- a template is provided for the first example
